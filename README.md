# Draw

Real-time collaborative whiteboard for [draw.querencia.art](https://draw.querencia.art).

Source is being migrated from an existing Vercel deployment into this repository. Feature work is organized in pull requests. Until deployment migration is verified, the live site and its Cloudflare Durable Object room data remain unchanged.

Built on [excalidraw-multi-tabs](https://github.com/MontejoJorge/excalidraw-multi-tabs) (MIT) and Excalidraw.
